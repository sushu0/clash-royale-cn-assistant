# 源码来源与公开整理

公开维护者：GitHub 用户 [sushu0](https://github.com/sushu0)。

Python 核心基于 [pyclashbot/py-clash-bot](https://github.com/pyclashbot/py-clash-bot)。本地派生版本的已提交基线为 `d83c198160d1ed8fcdb09e6c00a9ded4b39d29a3`，其中父提交 `34d11e57` 来自上游；本次公开快照还包含截至 2026-10-05 的未提交国服适配、页面识别、生命周期修复、桌面界面和对应离线测试。

`desktop-portable`、`portable-backend` 和安装器源码保存了面向其他用户的分享版实现，首次设置与数据目录属于各自安装位置。`desktop-wpf` 保存原开发版界面；`tools/archived` 和 `docs/archive` 保存研究、复盘和历史验证成果，具体输入与限制见各目录说明。

公开整理使用独立的源码副本。原项目的运行环境和文件保持原样；公开副本补充了可复现构建入口、相对编译路径、公众说明、离线 CI 和提交检查，并修复首次克隆后发现的验证问题。历史实验工具不作为当前可直接运行的正式入口。

本仓库使用新的发布历史，保留完整上游署名与许可证。作者运行数据库、事件日志、个人配置、进程锁、模拟器、第三方安装文件、备份及缓存不属于公开源码。游戏识别参考图及离线测试图保留，其游戏昵称按维护者的公开选择保留。
