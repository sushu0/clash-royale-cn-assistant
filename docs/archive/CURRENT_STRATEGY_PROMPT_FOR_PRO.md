## 当前规则的实际决策顺序（请以源码为准审查）

1. 只使用当前可见、确认在手且圣水足够的牌；一次决策最多出一张。点击手牌和落点后，用手牌变化或圣水扣费确认。出牌记录及冷却只在确认成功后推进。战斗额外轮询等待约 0.18 秒，单次出牌与确认通常约 1.2 秒。
2. 若敌公主塔仍有可见血条、填充比例 `<=0.04`、火球在手且可用，且敌人没有多人围攻我方国王塔，则单帧允许先火球收塔；这针对一次真实的敌塔 **126 HP** 漏收局。中等低血 `<=0.13` 的常规火球候选仍需连续可读两帧，且通常进入战斗约 140 秒以后。
3. 常规压力由己方 `y>=300` 的敌等级牌、少量可信的提早威胁模板和持续停在桥边的标记组成。通常连续两帧才确认压力；**首次出现至少 3 个且最深 `y>=330` 的标记**可立即响应。短暂消失又重现的压力不能借旧坐标出牌。
4. 压力成立时，按左右同路标记数量/深度选主防守路；深入 `y>=400` 优先。国王塔附近至少两名标记且最深 `y>=380` 时，有费优先在实际敌群位置打火球。若一边刚确认放过火枪、另一边至少 3 个敌标记接近河道 `y>=250`，且炮有费，先用炮接另一边。
5. 防守主路：近场 7 个以上同簇标记且未确认为空中时优先滚木；5 个以上大群或贴塔 3 个以上密集标记优先火球；确认空中优先火枪，不用地面炮/滚木冒充对空；确认冲塔类别优先加农炮；普通未知目标优先火枪提供通用伤害，其后按炮射程/位置选择炮、1费拖延、冰人牵引等。已出过炮/火枪后同路有短暂等待和 12 秒内费用预算，防止重复浪费；但我方塔血确实明显下降可打断等待。滚木、火球落点用当前可见同簇标记算，不打消失的旧目标。
6. 没有己方压力时，敌方半场同路 3–5 个标记临近河道，炮在手且至少 5 费则提早放炮；5 个以上桥前密集标记可火球，落点按最深标记 `y+35` 提前量；火枪可在预警路提前布置。单个河道预警会暂缓低费裸猪。
