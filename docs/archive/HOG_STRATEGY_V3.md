## 规则修复

| 情况 | v3执行规则 |
|---|---|
| 敌军标记仍在y<300 | 只作为河道预警，不混入己方受压人数，不取消已确认的冰人猪组合 |
| 单个浅压力，深度不超过330 | 有猪且至少7费时可施压，保留3费 |
| 近期已确认防守核心覆盖，小股压力且没有深压 | 有猪且至少6费时可反打，保留2费 |
| 任一路出现紧急深压 | 优先防守，不通过浅压力分支抢攻 |
| 同一路反复补火枪/炮 | 统计近12秒实际确认花费；普通压力核心预算4费，明显推进、增群或急压可放到8费 |
| 只有低费但没有输出核心 | 一次1费拖延后蓄费，避免连续低费单送；失败不计已投入 |
| 压力已在当前帧消失 | 短暂观察，不继续对缓存的旧坐标花费 |
| 空场有猪 | 6费即可出猪，保留2费；组合前置必须确认猪真在手 |
| 无猪、无低费的精确四卡锁手 | 真实四卡“滚木/炮/火球/冰人”全识别可用时，6费即可后置冰人解手，保留4费，不建立待跟猪状态；其他满费情形仍可后置火枪 |
| 已决定跟猪，同时技能也可点 | 野猪优先，技能不能抢掉跟进费用 |

v3初版不识别具体兵种与地空属性。用户在本轮测试中明确允许增加有限威胁识别，后续v3.1在本机实际截图基础上增加小范围模板分类；未匹配的敌军仍保持未知，不估算对手费用或牌序。“近期确认投入核心”只是有限覆盖假设，不证明该单位仍存活。

### 有限威胁识别的实际覆盖

当前启用的是**骷髅气球桶的空中状态**和**已见姿态的皇家巨人**。整身体模板在不同时间截图上效果不足，已弃用；局部模板排除等级数字与血条，并使用颜色、灰度等共同约束。模板来源自匹配、同局不同时间验证、跨会话验证分别记录。其他空军、地面人海和冲塔单位仍可能保持未知，不声称覆盖全部兵种。

策略只对已验证模板 `air_skeleton_barrel_top` 使用0.74相关分数门槛；其余类别默认0.88。相关分数不是概率。类别必须关联当前所选防守路、最深实际敌压40像素以内；可靠空中/冲塔类别可在y275开始提前防守，普通河道预警仍不取消组合。纯空中目标优先火枪和冰精灵，无有效牌时等待或在紧急条件下使用火球，不交滚木、炮、骷髅或冰人。

皇家巨人固定模板 `rush_royal_giant_head` 使用0.88门槛，仅它可从y250开始提前响应。当前在一局中的2张来源图和3张非来源时间图上通过，未取得跨对局皇家巨人正例，因此不能宣称跨皮肤或任意姿态有效。已确认冲塔时优先炮，无炮时考虑骷髅、冰精灵和火枪，不用冰人假装能拉住只攻击建筑的野猪。

地面人海模板没有可靠启用项；对应滚木优先规则只完成了离线准备。对于未识别类别但局部至少5个密集标记、已经深入到y300的情况，优先考虑可对地空的火球，而非先投入单体火枪。少于5个标记保持原有优先级。

本轮实图还发现中央两点只差1像素就把火枪放到最外侧的问题。焦点在x166–253且未到深压时使用中央防守点；深压仍使用靠后落点。

## 运行与取证修复

- 对1费卡增加一次受限的换牌确认读取，继续要求明确换牌或扣费；未知卡不算成功。
- 战斗计时区域连续45秒无变化时记录现场并恢复，避免长时间对冻结画面出牌。
- 新增紫色三星卡牌揭示模板，以及“拼图＋已解锁”双文字特征。文字用白色字形掩码匹配，避免稀有度改变背景颜色后失效。已进入奖励流程后，无星页面仍要求上方无HUD的平静背景与下方棋盘地板颜色、边缘纹理共同满足才继续点击。任意未知页面不点击；上下文可跨应用恢复保留，回大厅即清除。
- 不再只留前5场观察图、前10场结果图。出牌前后、观察、结果、奖励和未知页面各保留固定大小的滚动截图；日志写入路径、序号与SHA-256。引用旧记录前必须核对哈希，防止把已覆盖的新图当作旧图。
- 每次会话记录源码与模板哈希，默认仍使用腾讯包名及现有MEmu/ADB。

奖励返回修复必须区分截图回放与实际获胜返回验证；最终实战报告给出本轮实际覆盖情况。
