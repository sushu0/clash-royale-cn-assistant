# 皇室战争助手桌面版

桌面直接双击“皇室战争助手”，打开主界面后点击“开始运行”，进入无限随机卡组 1V1 对战。程序、日志、缓存和报告保存在 `D:\codex`。现有战绩和机器人配置继续使用。

| 操作 | 行为 |
| --- | --- |
| 桌面双击皇室战争助手 | 打开软件；不自动启动对战 |
| 开始运行 | 连接本机模拟器并开始无限对战 |
| 停止任务 | 停止后台机器人，保留模拟器和游戏 |
| 关闭窗口 / 收进系统托盘 | 隐藏主界面，后台继续运行，游戏还原为独立窗口 |
| 再次打开桌面图标 | 唤起同一个窗口，恢复游戏嵌入；不重复启动软件 |
| 系统托盘左键 / 双击 | 显示主界面 |
| 系统托盘右键 | 显示、开始、停止、退出菜单 |
| 应用 → 退出软件（停止任务） | 停止任务、还原游戏窗口并退出软件 |
| 任务异常暂停 | 自动保存游戏截图、具体原因、状态快照与日志 |
| 错误报告页面 | 查看最新报告、打开截图或打开所有报告所在文件夹 |
