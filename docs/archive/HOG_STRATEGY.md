# 国服 2.6 速猪规则

当前已进入v3修复与实战验证，见同目录 `HOG_STRATEGY_V3.md` 和完成后生成的 `hog-v3-validation.json`。以下保留早期规则与证据，不作为当前版本的新胜率结论。

当前默认运行器已切换为确定性速猪策略。使用的卡组角色是野猪、火枪、加农炮、火球、滚木、骷髅、冰精灵和冰人；实机已补充精英冰人、进化加农炮、进化火枪卡图。精英冰人保留独立变体身份，不当作普通卡图硬认。

| 场面 | 执行规则 |
|---|---|
| 身份、可下状态或圣水无法确认 | 等待新画面；不随机选择未知卡 |
| 近河道及我方半场连续两帧有敌军标记 | 暂停进攻，优先防守；短暂遮挡时保留压力状态 |
| 有效防守 | 中置炮吸引；火枪放受压路外侧；冰精灵、骷髅辅助拖延；精英冰人向中场牵引承伤 |
| 圣水少、未知单体近塔，火枪可用 | 先保证通用对空/对地输出，不先把费用花在滚木上 |
| 滚木 | 依据已观察的受压位置，从其后方滚过，不随机扔空地 |
| 火球 | 只对确认的密集压力区域施放；不猜塔血斩杀 |
| 空场单猪 | 前期至少 7 费出猪，保留 3 费；本场开始约 120 秒后保留 2 费 |
| 精英冰人＋野猪 | 两张都识别可用且至少 9 费，先冰人桥头承伤；确认部署成功、压力仍清空后才跟猪 |
| 猪后辅助 | 剩余至少 4 费时可跟一次冰精灵，仍保留 3 费 |
| 过牌 | 无持续压力、野猪不在可用手牌时，6 费起用骷髅或冰精灵过牌，保留至少 4 费；精英冰人不再用于后场过牌，保留给桥头组合与牵引 |
| 满费且野猪无法出击 | 野猪不在手或仍在冷却时：优先精英冰人桥头投资，铺垫下一波猪；否则可后置火枪解手牌，避免永远卡手 |
| 进攻路线 | 初始集中左路；连续三帧确认该公主塔已毁、另一塔仍在时换路；遮挡或低血空槽不当作塔毁 |
| 出牌确认 | 以手牌替换或圣水下降为证据，必要时等待第二帧；未确认就不推进组合和冷却状态 |

所有落点以本机 419×633 国服画面校准。策略仍复用现有大厅、匹配、战斗、结算和恢复循环。控制窗口的启动按钮会自动加载这版规则。

获胜后的即时奖励页已加入必要的返回流程：只有同时匹配实机星标和蓝色地面纹理才点击中央，逐步完成宝箱与奖励展示，最多12次点击后转恢复。大厅、战斗、匹配和登录实图不会通过这组双重匹配。

## 能力边界

这是一套基础规则，不会识别敌方具体卡牌或地空类型，也不会估算对手圣水/牌序。敌军红色等级标记被遮挡时可能漏检，数量只是画面线索，不是精确敌军数量。精英冰人的特殊技能目前不自动点击，避免在没有可靠单位位置和国服效果确认时额外消耗圣水。尚未实现精确塔血与法术伤害计算，因此不进行法术斩杀判断。

规则迭代中已观察到我方3冠、对方1冠的真实胜利及奖励画面。采用最后一套相同出牌规则的验证快照截至2026-09-25 15:06:24，共7场、1胜6负，137/143次尝试确认部署；最新连续运行段完成6场且没有恢复事件。这些结果不能证明长期胜率提升。旧版胜负检测只可靠识别部分失败画面，“未知”不能当作失败；不据此计算虚假的前后胜率。

即时奖励流程使用6个实际奖励画面与返回大厅画面回放，验证了6次中央点击、回大厅和请求下一场。加入该处理器后，尚未取得新的无人干预获胜回大厅样本；不能把画面回放称为完整实机获胜链路验收。详细快照见 `hog-strategy-validation.json`，回放结果见 `hog-reward-replay.json`。
