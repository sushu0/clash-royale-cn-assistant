# 历史技术说明归档

此目录保存项目开发期间的策略设计、问题复盘、页面导航覆盖、桌面交付和验收说明。文档中的版本、日期、局数、胜率、观察结果和验收结论均指各自记录时的实现与运行证据。它们用于展示开发过程，不代表当前版本对所有游戏环境的性能承诺。

原文保留了任务目录、实验名称和本机路径。文档引用的原始运行日志、JSON、事件 JSONL、SQLite 数据库、CSV、采集会话、审核 ZIP 和历史发行二进制没有整体上传；公开仓库另行提供活动源码、完整离线测试及其游戏测试截图。引用到被省略的运行资料时，应把该条记录视为历史说明，不能在缺少原始输入时独立复算其数字。

当前安装方式、开发环境和运行限制见根 README。Python 运行实现和测试位于 `py-clash-bot/`，可移植桌面源码位于 `desktop-portable/`，安装器位于 `installer/`，研究和验证脚本位于 `tools/archived/`。
