# 重地面候选研究：拒绝启用

本轮仅在本目录写候选和证据，没有修改运行中的 source、assets 或游戏状态。

较严格肤色条件（HSV H=0..15、S=55..180、V>=150），在等级牌附近取有限区域并遮挡已知塔身后，第16局三个大体积地面画面的最大连通面积分别为350、962、193。事件为12:59:59源帧、12:59:48另一帧、13:00:51另一次推进。它们都在同一局，不能作跨局验证。

这个候选仍不能启用：骷髅气球两个独立截图的同项面积为451、430，超过最弱重地面正例193。整批候选核图还确认了小型空中单位、重甲类空中单位、飞龙宝宝、骷髅气球和火焰/黄光反例；具体坐标和哈希在confirmed-counterexamples.json，图中序号对应rank。颜色连通包含了相同色系的道路、背景和命中特效，不能当作躯干大小。放宽肤色更严重；暗甲条件同样无法区分重甲亡灵与地面重甲。

B17及B19原先称为“国王塔旁巨人”的截图有两个独立敌方等级牌和金属头盔/红色饰物，身份应记为遮挡的裸臂地面单位，不能作为普通巨人确证正例。它们更接近野蛮人类，但此处也不强制归具体卡名。

结论为REJECT_DO_NOT_ENABLE。没有得到同时通过至少两个非相邻正例、跨局边界以及指定空军/小地面/塔身/特效反例的候选。已有小型巨人模板只有源帧强匹配，非源帧不足以启用；本轮没有降低运行阈值或添加猜测性标签。
