# 研究、复盘与验证工具归档

此目录保存项目开发过程中使用的研究、视觉校准、策略复盘、桌面界面检查、模拟器交互检查和打包验收源码。子目录沿用原开发任务名称；顶层脚本对应早期策略研究工具。这些工具用于展示实现过程和供开发者复用，当前产品的安装与启动入口见仓库根 README。

归档源码保留原逻辑，因此部分脚本仍引用原开发目录 `D:\codex\CodexWork\clash`、特定日期的运行文件或本机工具位置。分析输入、运行日志、SQLite 数据库、事件 JSONL、个人配置、屏幕采集会话和历史二进制包没有随本目录发布。需要在新机器使用某个历史工具时，应先按其读写路径准备独立输入与输出；含安装、运行切换或修复功能的脚本会执行其源码中声明的操作。

主要内容包括：

- `batch5_*`、`candidate_*`、`gold_*`、`v2_*`、`v3_*`：图像识别、威胁线索和回归复核。
- `567-evo`、`567-optimize`、`winrate33`：候选策略、角色识别、塔血观察和实验记录分析。
- `random-mastery`、`random-strategy`、`loss-optimization-20261004`：随机卡组、熟练度奖励和对局结果证据复盘。
- `navigation-learning-20261004`、`no-play-repair-20261003`：页面导航、参考图生成和手牌校准。
- 桌面、WPF 与生命周期任务目录：界面布局、嵌入窗口、后端通讯、停止流程和发布包验收代码，包括 C# 假后端及客户端检查工程。
- `friend-installer-20261005/prepare_backend.py`：早期便携后端适配工具，原实现从已冻结后端派生，因此需要对应冻结输入；当前可重建的公开构建流程见主文档。

备份源码、修改前快照、重复冻结源码、下载的第三方程序、依赖环境、编译缓存和测试生成的临时会话没有纳入归档。可移植桌面实现位于 `desktop-portable/`，安装器工程位于 `installer/`，活动 Python 实现及离线测试位于 `py-clash-bot/`。

发布前对本批历史 Python 源码进行了 AST 语法解析，对 PowerShell 源码进行了解析器检查，对工程与 XAML 文件进行了 XML 检查。检查通过代表源码结构可解析；没有重新执行历史实验，也没有重新证明历史指标或当时机器上的运行状态。
