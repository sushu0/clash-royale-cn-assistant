# 有限威胁识别最小交付

## 本次实际启用范围

仅启用 `air_skeleton_barrel_top`：真实截图中三个红色气球悬吊桶的稳定顶部局部。输出 `kind="air"`。不声称支持全部空军；飞龙、普通大气球、其他空军、rush、swarm 均未启用，没有可靠匹配则省略，语义为 unknown。

接口：`read_cn_threats(frame, enemies=None) -> list[dict]`。必须由调用方先确认战斗画面。`x/y` 原样保留输入敌军等级牌压力点（标签中心 +16），不是测量所得脚点。只在相应敌方红标签附近的小窗口匹配，不向整条兵线推广类别。

每次输出带 `template_id`、原截图路径、原截图 SHA256、实际匹配 `sprite_bbox`、`confidence_threshold` 与 `red_fraction`。模板由真实精灵顶部裁切，未包含等级数字或血条；未下载图片、未训练模型、未使用 YOLO/RL/LLM。
